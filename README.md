# ShopWise

ShopWise is a full-stack e-commerce application built to simulate a real-world online shopping platform.

The project focuses on building a production-style backend using Java and Spring Boot, with a React frontend, PostgreSQL for persistent data, Redis for caching, and JWT-based authentication.

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA / Hibernate
- PostgreSQL
- Redis
- REST APIs

### Frontend
- React
- Vite
- JavaScript
- Tailwind CSS

### Infrastructure
- Docker
- Docker Compose
- AWS EC2
- GitHub Actions
